# Небесные тела — полный справочник (`hev.body.json`)

Файл данных: **`hev.body.json`**  
Связанный код:
- `bodies.js` — загрузка, меши, орбиты, кольца, атмосфера, labels
- `bodyParameters.js` — диаметр, площадь, breakdown поверхности, форматирование
- `shaders.js` — звезда, атмосфера, gravity well, частицы
- `camera.js` / `ui.js` — панель «Общая сводка / Геоданные / Климат»
- `saveSystem.js` — сохранение орбит, вращения, population, stock
- `resourceStorage.js` / `population.js` — ресурсы и население по телу

Локализация имён и описаний: объекты `{ "ru", "en", "de" }` через `locName()` / `locPick()`.

---

## 1. Идентификация и иерархия

| Параметр | Тип | Обязателен | Описание |
|----------|-----|------------|----------|
| `id` | `number` | да | Уникальный ID. Системы: `1000+`, Солнце `0`, планеты `1–12`, Альфа Центавра `20+` |
| `name` | `{ru,en,de}` | да | Отображаемое имя в title-bar, info, квестах |
| `type` | `string` | да | См. таблицу типов ниже |
| `parent` | `number \| null` | да | ID родителя: у звезды/системы `null`, у планеты — звезда, у луны — планета |
| `children` | `number[]` | да | Список ID дочерних тел (может быть `[]`) |
| `starSystemId` | `number` | нет | К какой системе относится тело (для фильтрации уровней камеры / UI) |

### Типы (`type`)

| Значение | Меш | Поведение |
|----------|-----|-----------|
| `starSystem` | `Object3D` (невидимый узел) | Корень системы, `centerX/Z`, без текстуры |
| `star` | Сфера + `sunFragmentShader` | PointLight, плазма/пятна, атмосфера-хромосфера |
| `planet` | Сфера + `MeshPhongMaterial` | Орбита вокруг parent, здания, ресурсы |
| `moon` | Сфера + Phong | Орбита вокруг планеты |

## 2. Сцена / 3D-трансформ

| Параметр | Тип | Описание |
|----------|-----|----------|
| `size` | `number` | **Радиус меша** в единицах сцены (не путать с `radius` в км). Солнце ≈ 2, планеты ≈ 1–1.5, луны ≈ 0.5 |
| `distance` | `number` | Орбитальный радиус от `parent` в единицах сцены. У звезды/системы обычно `0` |
| `centerX`, `centerZ` | `number` | Мировая позиция для `starSystem` / звезды без parent (Солнце: `0,0`) |
| `orbitalStartAngle` | `number` (рад) | Стартовый угол на орбите. В рантайме: `mesh.userData.orbitAngle` |
| `rotationStartAngle` | `number` (рад) | Стартовый поворот вокруг оси Y. В рантайме: `mesh.rotation.y` |
| `texture` | `string \| null` | Путь к diffuse-текстуре (`assets/textures/planets/...`). У `starSystem` — `null` |
| `specularMap` | `string` | (опц.) Specular-карта: блик сильнее на ярких зонах карты (океаны). Без неё — равномерный узкий Phong-блик |

**Сохранение:** `orbitAngle` и `rotation.y` пишутся в сессию (save v2.2) и восстанавливаются при загрузке.

## 3. Время и физика (данные для UI)

| Параметр | Тип | Единицы / смысл |
|----------|-----|-----------------|
| `day` | `number` | Период осевого вращения (в игровых «сутках» или земных днях — как задано автором). `0` у систем |
| `year` | `number` | Орбитальный период вокруг parent. У звезды/системы `0` |
| `age` | `number` | Возраст тела (лет). Показывается в info «Возраст» |
| `radius` | `number` | **Физический** радиус в **км** (для панели метрик, не для меша) |
| `orbitalRadius` | `number` | Физический орбитальный радиус в **км** (например 1 AU ≈ 1.496e8). У звезды `0` |
| `gravityWellRadius` | `number` | Физический радиус ближней орбиты / колодца в **км** (для UI) |
| `gravityWellMultiplier` | `number` | Множитель для **сцены**: радиус колодца меша = `size * gravityWellMultiplier` |
| `avgSurfaceTemp` | `number \| null` | Средняя температура поверхности (°C). `null` если не задана |

Производные в `bodyParameters.js` (не хранятся в JSON):
- `diameter = radius * 2`
- `surfaceArea = 4 * π * radius²`
- breakdown площадей из `surfacePercents`

## 4. Поверхность (`surfacePercents`)

Объект процентов покрытия. Ключи (все `number`, сумма логических групп может не быть 100 — UI показывает как есть):

| Ключ | i18n | Смысл |
|------|------|-------|
| `land` | `surface.land` | Суша |
| `water` | `surface.water` | Вода (океаны) |
| `forests` | `surface.forests` | Леса |
| `deserts` | `surface.deserts` | Пустыни |
| `mountains` | `surface.mountains` | Горы |
| `plains` | `surface.plains` | Равнины |
| `steppes` | `surface.steppes` | Степи |
| `rivers` | `surface.rivers` | Реки |
| `lakes` | `surface.lakes` | Озёра |
| `glaciers` | `surface.glaciers` | Ледники |

`calculateSurfaceBreakdown(surfaceArea, surfacePercents)` → абсолютные км² по каждому ключу для вкладки «Поверхность».

## 5. Ресурсы на теле (`resources`)

Стартовое / текущее состояние экономики тела. В рантайме может расширяться; в сейв уходит актуальный `stock` и население.

| Поле | Тип | Описание |
|------|-----|----------|
| `population` | `number` | Жители («Всего жителей») |
| `technologies` | `number` | Очки / запас технологий на теле |
| `stock` | `object` | Словарь `resourceId → количество` (кг/шт по типу ресурса) |
| `energy` | `number` | (опц.) энергия, если используется плоско |
| `raw` / `materials` / `food` | `number` | (опц., legacy) агрегаты; основной путь — `stock` |

Пример `stock`:
```json
"stock": {
  "RES_WATER": 50.0,
  "RES_ORE": 25000.0,
  "RES_METAL": 10000.0,
  "RES_FOOD": 10.0
}
```

Лимиты склада считаются по зданиям с `IsResourceStorage` на этом `parentBodyId`.

## 6. Кольца и пояса частиц

| Параметр | Тип | Описание |
|----------|-----|----------|
| `rings` | `bool` | Создавать ли кольцевую систему |
| `ringCount` | `number` | Число колец / слоёв |
| `ringDensity` | `number` | Число частиц (порядок 10³–10⁴) |
| `ringSpacing` | `number` | Шаг радиуса между кольцами (сценные ед.) |
| `ringThickness` | `number` | Толщина / разброс по радиусу |

Используется в `bodies.js` при `rings: true` (частицы + shader). У планет без колец — `rings: false`, остальные ring-* можно не указывать.

## 7. Атмосфера (визуал)

Только при `hasAtmosphere: true`. Шейдер: объёмный optical depth, `ρ = exp(−h/H)`, лимб-маска, день/ночь от позиции звезды.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `hasAtmosphere` | `bool` | Вкл/выкл оболочки |
| `atmosphereColor` | `string` \| `[r,g,b]` | Hex (`#6BA3FF`), `rgb()` или массив 0–1 / 0–255 |
| `atmosphereScale` | `number` | Верхняя граница = `size * scale` (типично 1.03–1.22) |
| `atmosphereIntensity` | `number` | Сила дымки (планеты ~0.2–1.5, звёзды ~1.5) |
| `atmosphereScaleHeight` | `number` | Доля толщины H; меньше → быстрее спад к космосу |

**Не** влияет на геймплей напрямую — только рендер.  
У `starSystem` атмосферы нет. У Меркурия / Луны / Деймоса / Цереры — `hasAtmosphere: false`.

## Облака (визуал)

Только при `hasClouds: true` **и** заданном `cloudMap`. Слой — child-сфера чуть выше поверхности (`cloudScale` ≈ 1.012), поэтому **вращается вместе с телом**.  
Освещение то же, что у планеты (день/ночь от PointLight своей звезды). Низкий specular — без пересвета.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `hasClouds` | `bool` | Включить облачный слой |
| `cloudMap` | `string` | Путь к текстуре облаков (alpha/яркость = маска) |
| `cloudDensity` | `number` | 0…1, влияет на opacity (0.25…0.8) |
| `cloudScale` | `number` | (опц.) радиус слоя / size, по умолчанию 1.012 |

Пример (Святая Русь):
```json
"hasClouds": true,
"cloudMap": "assets/textures/planets/earth_clouds.jpg",
"cloudDensity": 0.55
```


## Ночные огни городов (визуал)

| Параметр | Тип | Описание |
|----------|-----|----------|
| `hasCityLights` | `bool` | Включить слой огней |
| `cityLightsMap` | `string` | Текстура ночных огней (чёрный фон, яркие города) |
| `cityLightsIntensity` | `number` | Яркость (по умолчанию ~1.2) |
| `cityLightsScale` | `number` | Радиус слоя / size (≈1.004) |

**Правила:** слой создаётся только при `colonized: true`. В шейдере огни видны **только на ночной стороне** (AdditiveBlending). При смене `colonized` в рантайме `lights.visible` обновляется каждый кадр.


## Полярное сияние (визуал, только шейдер)

| Параметр | Тип | Описание |
|----------|-----|----------|
| `hasMagneticField` | `bool` | Если true — рисуется aurora-оболочка |
| `auroraIntensity` | `number` | Яркость (опц., ~1.0) |
| `auroraScale` | `number` | Радиус / size (≈1.09) |

Без текстур: несколько шумовых «туманных» завес у полюсов (зелёный / циан / фиолет / розовый), мягкие края.  
Анимация: `time += dt * timeSpeed`.  
Видимость: **только** уровень камеры `1ZC` («Планеты и луны»); на `2ZC` «Планеты» и выше — скрыто.

## 8. Геймплей и застройка

| Параметр | Тип | Описание |
|----------|-----|----------|
| `colonized` | `bool` | Тело колонизировано (доступ к постройкам / UI) |
| `has_technoport` | `bool` | Есть технопорт |

## 10. Что считается в коде, а не в JSON

| Вещь | Где |
|------|-----|
| Диаметр, площадь поверхности | `calculateBodyParameters(radius)` |
| км² по биомам | `calculateSurfaceBreakdown` |
| Тунеядцы / созидатели / бездомные | `population.js` от зданий и population |
| Энергия (производство/хранение) | здания + `energyStorage.js` |
| Текущие углы орбиты/оси после старта | `mesh.userData.orbitAngle`, `mesh.rotation.y` |
| Gravity well **меш** (диск/сетка) | `size * gravityWellMultiplier` в `bodies.js` |

## 11. Связь с сейвами (v2.2+)

В снимок сессии по каждому телу уходит в том числе:
- `orbitAngle`, угол вращения
- `resources.population`, `resources.stock`
- специалисты, `locationBuildings`, мощность рецептов

Стартовые значения в JSON — база **новой** игры; после save/load приоритет у сессии.

## 13. Шейдеры звёзд (напоминание)

| Контекст | Шейдер | Логика дистанции |
|----------|--------|------------------|
| Основная карта | `sunVertexShader` / `sunFragmentShader` | `cameraDistance` = высота камеры игры |
| Интро | `introSunVertexShader` / `introSunFragmentShader` | реальная дистанция камера↔звезда в сцене интро |

Не смешивать: пороги разные, иначе в одном из режимов пропадут пятна/плазма.


## Межзвёздная туманность (`type: interstellarNebula`)

| Параметр | Описание |
|----------|----------|
| `children` | ID звёздных систем внутри |
| `centerX/Z` | Позиция на **глобальной** сетке |
| `size` | Размер меша туманности (мир. ед.) |
| `nebulaColors` | До 4 цветов (hex) |
| `nebulaGeometry` | `{ shape, lobes, noiseScale, edgeSoftness }` |
| `distanceLy` | Расстояние (св. лет) для UI |
| `age` | Возраст |
| `developed` | Освоена (пока false → только «Общее») |

Звёздные системы с `parent` = id туманности позиционируются **относительно** неё.  
Визуал только на уровне камеры `4ZC` (плавный opacity). Звёзды на 4ZC: экранный размер ~10px + восьмиконечный шейдер.


## plannedConstruction

| Поле | Тип | Описание |
|------|-----|----------|
| `plannedConstruction` | `boolean` | Если `true`, в модалке здания доступны **плановые инпуты** у кнопок Построить / Разобрать / Улучшить / Ухудшить: целевое количество (шт.) или уровень. Суммируются ресурсы и время на весь диапазон. Пока задействовано на Святой Руси для теста; позже статус будет меняться геймплеем. |

## Тип `galaxy` (уровень высоты 5ZC — Галактика)

| Поле | Тип | Описание |
|------|-----|----------|
| `type` | `"galaxy"` | Корневой объект галактической системы координат |
| `children` | `number[]` | id межзвёздных туманностей |
| `size` | `number` | Физический размер плоскости Млечного Пути в мировых единицах |
| `age` | `number` | Возраст галактики (лет) |
| `radius` | `number` | Радиус (св. лет), для UI |

### Уровни высоты камеры

| id | min–max | Название |
|----|---------|----------|
| 1ZC | 3–10 | Планеты и луны |
| 2ZC | 10–17 | Планеты |
| 3ZC | 17–400 | Звёздная система |
| 4ZC | 400–6500 | Межзвёздная туманность |
| 5ZC | 6500–25000 | **Галактика** |

На 5ZC: скрыты звёзды/системы/планеты/луны; видны таблички туманностей; рисуется плоскость Млечного Пути + межгалактическая пыль (`galaxy.js`). Туманности медленно вращаются вокруг центра галактики (`year` ≈ 230 млн лет в сутках). Орбиты туманностей **не** рисуются. Двойной клик по туманности / зум вниз над ней → спуск на 4ZC к её центру.

### Межзвёздные туманности в галактике

| Поле | Описание |
|------|----------|
| `parent` | id галактики (3000) |
| `galaxyId` | id галактики |
| `orbitalRadius` | расстояние от центра галактики (из centerX/Z) |
| `orbitalStartAngle` | стартовый угол орбиты |
| `year` | период обращения вокруг центра (земные сутки) |
| `nebulaColors` | цвета для 2D-плоскости + particles |
